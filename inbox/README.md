# Inbox

Drop context files here by project. Once reviewed, the relevant content gets synthesized into:
- The project's `CLAUDE.md` (persistent context)
- Skills in `~/.claude/skills/` (repeatable workflows)
- Obsidian vault notes (long-term PKM)

## How to use

1. Drop `.md` files into the relevant project subfolder
2. Tell Claude: "process my inbox" or "process the Gioia inbox"
3. Claude will read the files and propose what goes where
